# পুজোর ঝুলি

গ্যালারিতে পড়ে থাকা পুজোর ছবি, মিনিটখানেকে Instagram-রেডি।

পুজোর সব ছবি একবারে দাও। সাইট নিজে থেকে একই পোজের ছবি থেকে একটা রাখে, ঝাপসা ছবি বাদ দেয়, কার চোখ বন্ধ দেখে, আর ষষ্ঠী থেকে দশমী দিন ধরে সেরা ছবিগুলো সাজায়। তারপর তিনটে জিনিস দেয়:

- **পুজোর মুডবোর্ড:** ৮টা বাংলা পুজোর মুডবোর্ড টেমপ্লেট (১০৮০x১৯২০)। AI-র বাছা ছবি ফাঁকা ফ্রেমে নিজে থেকে বসে যায়। টেমপ্লেট স্টুডিওতে ছবি বদলানো, নিজের ফোন থেকে ছবি দেওয়া, স্টিকার টেনে বসানো আর বাংলা লেখা যোগ করা যায়।
- **পুজোর হিসেব:** ১০৮০x১৯২০ story card, মজার খোঁচা দেওয়া লাইন সহ
- **ক্যাপশন:** কপি করার মতো বাংলা ক্যাপশন আর হ্যাশট্যাগ

সব কাজ ব্রাউজারেই হয়। কোনো server নেই, ছবি কোথাও আপলোড হয় না।

## চালানো

```bash
npm install          # postinstall copies the MediaPipe WASM into public/
npm run dev          # http://localhost:5190
npm run build        # typecheck + production build into dist/
npm run model        # re-download the face model (already committed in public/)
```

Node 20+.

## Vercel-এ তোলা

1. GitHub-এ push করো, Vercel-এ "New Project" থেকে repo বাছো। Framework: Vite, build `npm run build`, output `dist`.
2. ডিপ্লয়ের পরে `src/config.ts`-এ `SITE.link` বদলে আসল ঠিকানা দাও। এটা "পুজোর হিসেব" কার্ডের নিচে লেখা থাকে। মুডবোর্ডের ছবিতে কোনো লিংক বা ছাপ থাকে না।

## যা বদলাতে পারো (`src/config.ts`)

| কী | কোথায় |
| --- | --- |
| পুজোর তারিখ (ষষ্ঠী থেকে দশমী) | `PUJO_DAYS`। **লঞ্চের আগে পঞ্জিকা মিলিয়ে নিও।** ২০২৬-এর তারিখগুলো আন্দাজে বসানো (১৭ থেকে ২১ অক্টোবর)। |
| রাত কটা পর্যন্ত আগের দিন ধরা হবে | `DAY_STARTS_AT_HOUR` (ভোর ৫টা) |
| কতগুলো ছবি নেওয়া যাবে, কটা বাছবে | `LIMITS` |
| সাইটের নাম আর লিংক | `SITE` |

## AI কীভাবে কাজ করে

| কাজ | কী দিয়ে | ফাইল |
| --- | --- | --- |
| তারিখ, সময়, সামনের ক্যামেরা, GPS | EXIF (`exifr`) | `src/lib/exif.ts` |
| ঝাপসা ছবি | Laplacian variance, সবচেয়ে শার্প ৩টে টাইল ধরে | `src/lib/image.ts` |
| একই পোজ | 64-bit dHash + সময়ের ব্যবধান (৯০ সেকেন্ডে ১২ বিট, ৫ মিনিটে ১০ বিট) | `src/lib/analyze.ts` |
| মুখ, চোখ বন্ধ, হাসি | Google MediaPipe Face Landmarker (blendshapes), ফোনের GPU বা CPU-তে | `src/lib/faces.ts` |
| কোন ছবি নেবে | দিনপ্রতি কোটা, মানুষ আর ঠাকুর মিশিয়ে, কাছাকাছি দেখতে ছবি বাদ | `src/lib/select.ts` |
| পুজোর হিসেব | ছবির সংখ্যা, দিন, সময়, মুখ, লোকেশন থেকে | `src/lib/stats.ts` |

মডেল (`public/mediapipe/face_landmarker.task`, Apache-2.0) রিপোতেই রাখা, তাই Google-এর সার্ভারের উপর নির্ভর নেই। প্রথমবার ব্রাউজার মোটামুটি ৭ MB (gzip করা হলে) নামায়, তারপর cache থেকে চলে। ধীর নেটওয়ার্কে বা Data Saver চালু থাকলে মডেল আগে থেকে নামায় না, ছবি দেওয়ার পরে নামায়।

## 3D আর অ্যানিমেশন

- `src/three/`: React Three Fiber দৃশ্য। মাটির প্রদীপ (`Diya.tsx`), চারপাশে ঘোরা পোলারয়েড (`Cards.tsx`), বিশ্লেষণের সময় ছবিগুলো ঘুরতে ঘুরতে আগুনে পড়ে ("অগ্নিপরীক্ষা"): ভালো ছবি সোনালি হয়ে উপরে ওঠে, বাকিগুলো পুড়ে যায়। শেষে বাছা ছবিগুলো প্রদীপ ঘিরে আরতির মতো ঘোরে (`Ring.tsx`), টেনে ঘোরানো যায়।
- UI অ্যানিমেশন: `motion` (শব্দে শব্দে হেডলাইন, স্ক্রোলে কার্ড ওঠা, ট্যাব, বটম শিট), হেলানো 3D story card (`TiltCard.tsx`)।
- 3D দৃশ্য শুধু হোম পেজের প্রথম অংশে থাকে, আর স্ক্রোল করে সেটা পেরিয়ে গেলে আঁকা বন্ধ হয়ে যায়। নিচের সেকশনগুলোর রং সলিড।

### নতুন মুডবোর্ড টেমপ্লেট যোগ করা

1. ছবিটা (৯:১৬, ফ্রেমের ভেতরটা একদম সমান এক রঙের) রাখো `moodboard/originals/<id>__story.webp` নামে।
2. `moodboard/templates.json`-এ নাম আর কটা ছবি ধরে লেখো: `"<id>": { "name": "বাংলা নাম", "photos": 3 }`।
3. চালাও `npm run templates`। স্ক্রিপ্ট (`scripts/build-templates.mjs`) ফাঁকা ফ্রেমগুলো খুঁজে ঠিক সেই আকারে কেটে নেয় (হেলানো ফ্রেম, আর ফ্রেমের ভেতরের লেখাও), তারপর `public/templates/`-এ স্বচ্ছ ছবি আর ছোট preview, আর `src/editor/templates.generated.json`-এ ফ্রেমের মাপ লেখে।
4. `moodboard/debug/<id>__story.png` খুলে দেখো: প্রতিটা ফ্রেম গোলাপি আর লাল বাক্সে ঘেরা থাকা উচিত। ফ্রেমের ধারে কাগজের দাগ থেকে গেলে `templates.json`-এ `"tune": { "colour": 44, "reach": 14, "grow": 3 }` দিয়ে আবার চালাও।
5. ঠিক থাকলে `src/editor/templates.ts`-এর `VERIFIED` তালিকায় `"<id>__story"` যোগ করো।
- `prefers-reduced-motion` চালু থাকলে 3D দৃশ্য ধীরে চলে।

## জানা সীমাবদ্ধতা

- **GPS প্রায়ই থাকে না।** Android আর iPhone গ্যালারি থেকে ছবি দেওয়ার সময় অনেক সময় লোকেশন মুছে দেয়। তাই "কত কিমি ঘুরেছ" লাইনটা শুধু তখনই আসে যখন অন্তত ৬টা ছবিতে লোকেশন থাকে।
- **ঠাকুরের মুখকেও মানুষের মুখ ভাবতে পারে।** তখন "ঠাকুর বনাম নিজের ছবি" হিসেবটা একটু এদিক-ওদিক হবে। সামনের ক্যামেরার ছবি সবসময় "নিজের" ধরা হয়।
- **বড় গ্রুপ ছবিতে দূরের ছোট মুখ বাদ পড়তে পারে।** মডেলটা সেলফির দূরত্বের মুখের জন্য বানানো।
- **ডেস্কটপ Chrome-এ iPhone-এর HEIC ছবি খোলে না।** ফোন থেকে সাইট খুললে iPhone নিজেই JPG করে দেয়।
- **Instagram-এ সরাসরি শেয়ার** হয় ফোনের share sheet দিয়ে (Android Chrome, iPhone Safari)। ডেস্কটপে ZIP নামে।
- গতি: ডেস্কটপে প্রতি ছবিতে মোটামুটি ০.১ সেকেন্ড (ডিকোড ৪৫ ms + মুখ চেনা ৫০ ms)। ফোনে এর ২-৩ গুণ সময় লাগবে বলে আন্দাজ, আসল ফোনে মেপে দেখা হয়নি।
